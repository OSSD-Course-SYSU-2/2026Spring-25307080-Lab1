# 打地鼠游戏  一次开发多端部署项目
## 项目简介
本项目基于HarmonyOS ArkTS开发经典打地鼠游戏，配置双设备打包，一套代码同时兼容手机、平板，满足一次开发多端部署课程要求。
程序包含登录、锤子选择、开局倒计时、游戏对战、关卡结算完整业务流程。

## 开发环境
- 开发工具：DevEco Studio
- 开发语言：ArkTS
- 目标API版本：API 11
- 项目构建工具：hvigor

## 核心功能
1. 页面流转：用户名登录 → 三款锤子选择 → 3s倒计时 → 游戏界面 → 关卡结果页
2. 锤子差异化倍率
    - 木锤：得分倍率 ×1.0
    - 金锤：得分倍率 ×1.5
    - 雷神锤：得分倍率 ×2.0
3. 连击计分系统：连续命中地鼠累计连击数，连击越高额外得分加成越高，加成上限50%
4. 三档递进关卡（通关条件：单关分数≥目标总分80%）
    - 第1关：限时30s，地鼠弹出间隔1000ms，达标线240分（满分300×80%）
    - 第2关：限时30s，地鼠弹出间隔800ms，达标线280分（满分350×80%）
    - 第3关：限时30s，地鼠弹出间隔550ms，达标线320分（满分400×80%）
5. 游戏控制：对局内支持暂停/继续游戏、一键退出返回登录页
6. 通关判定：达标进入下一关，分数不足则本关失败；通关全部3关即为游戏完结

## 一次开发多端部署实现（作业核心）
1. 配置`module.json5`：`"deviceTypes": ["phone","tablet"]`，打包产物同时适配手机、平板设备
2. 屏幕自适应逻辑：通过屏幕宽度区分设备，宽度＞600vp自动按平板大屏放大字体、地洞尺寸；手机设备自动缩小布局
3. 实测验证：MatePad Pro11平板模拟器、手机模拟器共用同一套安装包，UI自动适配屏幕尺寸
